# Code of Conduct

## Our Standard

The unpwn community is committed to a respectful, constructive, and security-conscious collaboration environment.

Examples of expected behavior include:

- treating contributors and users with respect
- giving technical feedback without personal attacks
- explaining security concerns clearly and proportionately
- accepting that maintainers may reject unsafe or overly complex changes
- protecting personal data and live account information
- respecting coordinated vulnerability disclosure

Unacceptable behavior includes:

- harassment, intimidation, discrimination, or personal attacks
- publishing another person's private information without permission
- posting credentials, cookies, reset links, tokens, or sensitive recovery data
- using project discussions to facilitate unauthorized account access
- knowingly submitting malicious workflows, links, or automation
- pressuring maintainers to merge changes without appropriate review

## Scope

This code applies in repository issues, pull requests, discussions, reviews, security reports, and other project spaces.

## Enforcement

Maintainers may edit or remove contributions and comments that violate this code. They may temporarily or permanently restrict participation when necessary to protect the project or its community.

Security-sensitive material may be removed immediately from public view.

## Reporting

For general conduct concerns, contact the maintainers through GitHub without publishing private information.

For security vulnerabilities, follow [SECURITY.md](SECURITY.md) and use private vulnerability reporting where available.

## Good-Faith Technical Disagreement

Strong disagreement about architecture, security, scope, or maintainability is allowed. Critique the proposal, evidence, or implementation rather than the person.
