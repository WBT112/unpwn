# Security Policy

## Security Philosophy

unpwn handles security-sensitive recovery workflows. Security and transparency have priority over convenience.

## Important Limitations

unpwn cannot guarantee account security if the device running it is compromised.

Users should run unpwn from a trusted environment whenever possible.

## Sensitive Data

unpwn must:

- keep recovery data local
- encrypt stored recovery information
- avoid logging secrets
- avoid collecting user credentials remotely

## Reporting Security Issues

If you discover a security vulnerability, please report it responsibly through the repository security reporting process.

Do not publicly disclose vulnerabilities before maintainers have had time to investigate and address them.
